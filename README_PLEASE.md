# Exclusivo_Games
   Aqui eu crio jogos simples com diferentes linguagens de programação, como: Java e HTML(com CSS + JS).
   A principal finalidade é praticar sintaxe de diferentes linguagens enquanto aperfeiçoo minha lógica de programação, senso crítico e criatividade. O ato de fazer todo o código à mão permite que eu aprenda e decore mais facilmente as estruturas do código.
