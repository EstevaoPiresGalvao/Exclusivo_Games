# Exclusivo_Games
   Aqui eu crio jogos simples com diferentes linguagens de programação (java, html, etc).
   A principal finalidade é praticar a sintaxe de diferentes linguagens enquanto aperfeiçoo minha lógica de programação, senso crítico e criatividade. O ato de fazer todo o código à mão permite que eu aprenda e decore mais facilmente as estruturas da linguagem estudada.
